# Student Management System

A full-stack application for managing students, built with Spring Boot (Backend) and Next.js (Frontend).

## Backend Setup (Spring Boot)
1. Navigate to the `backend/` directory.
2. Run `mvnw spring-boot:run` to start the backend server.
3. The server runs on `http://localhost:8080`.

## Frontend Setup (Next.js)
1. Navigate to the `frontend/` directory.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the frontend development server.
4. The application runs on `http://localhost:3000`.
